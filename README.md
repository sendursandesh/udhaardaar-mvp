# Udhaardaar

Udhaardaar is an Android application for digitally documenting and tracking credit, loans, advances, rentals and other payable/receivable transactions.

## V3.2.2 verification build

This branch is the V3 development baseline for the final V3.2.2 verification build. The Android build workflow runs automatically on pushes to this branch and uploads the debug APK as a GitHub Actions artifact when compilation and APK verification succeed.

## V3.2.2 scope

- Professional dashboard with clickable credit metrics
- Borrower/profile search by name, mobile, PAN, Aadhaar and unique ID
- Borrower profile and credit-history review before new registration
- Credit-type-specific registration including rental/lease and trade credit
- Trade-credit invoice upload and OCR support
- Guarantor availability/details
- Optional bank/NACH linkage
- Digital documentation, consent and standard T&C
- Repayment schedules, payment recording and reminders
- Optional profile photographs
- Live validation for required fields and 10-digit mobile numbers
