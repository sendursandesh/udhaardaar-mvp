# Udhaardaar

Udhaardaar is an Android application for digitally documenting and tracking credit, loans, advances, rentals and other payable/receivable transactions.

## V3.2.4 corrected verification build

The V3 development baseline now builds the corrected V3.2.4 APK workflow. The build applies strict identity-field validation, live profile search, and an explicit authorised-view/consent gate before protected borrower information is displayed.

## Core privacy principle

No third-party financial, credit, repayment or protected profile information is to be disclosed merely because a profile can be searched. Protected information requires explicit authorised consent.

## V3 scope

- Professional dashboard with clickable credit metrics
- Borrower/profile search by name, mobile, PAN, Aadhaar, GSTIN and unique ID
- Live search as characters are entered
- Authorised-view consent gate before protected borrower history
- Credit-type-specific registration including rental/lease and trade credit
- Trade-credit invoice upload and OCR support
- Guarantor availability/details
- Optional bank/NACH linkage
- Digital documentation, consent and standard T&C
- Repayment schedules, payment recording and reminders
- Optional profile photographs
- Strict validation for PAN, GSTIN, email, Aadhaar, PIN and 10-digit mobile numbers
